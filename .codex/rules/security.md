# 安全要求（强制）

- 不在源码、Git、前端 bundle、日志或测试快照中放置真实密钥、数据库密码、JWT secret、第三方 AppSecret 或生产账号。
- 所有密钥通过环境变量读取；`.env.example` 只提供 `change-me` 或空值。`.env` 必须被 Git 忽略。
- 前端不保存明文密码；现有“记住我”加密存储不得继续扩散到新页面，新增记住登录方案需单独评审。
- 后端密码使用 bcrypt 哈希；登录失败提示不得区分“用户不存在”和“密码错误”。
- 除明确白名单外，接口必须要求 JWT；权限判断以服务端为准，不能只依赖前端隐藏按钮。
- 所有入参使用 DTO + class-validator 校验；开启 `whitelist`，拒绝未声明字段。
- 查询使用 TypeORM 参数绑定或 query builder；禁止字符串拼接 SQL、排序字段和表名。
- 富文本、HTML 和文件名按不可信输入处理；下载与上传校验扩展名、MIME、大小和存储路径。
- 上传文件不得直接执行；公开访问目录只允许白名单类型，敏感文件走鉴权下载。
- 日志不得记录密码、完整 token、密钥、身份证号、手机号等敏感数据；错误信息不泄露内部堆栈和 SQL。
- 生产 CORS 不得放开任意来源；Swagger、调试端点和测试账号默认不对外暴露。
- 新增依赖前检查维护状态和安全风险；不引入来源不明或长期未维护的包。
